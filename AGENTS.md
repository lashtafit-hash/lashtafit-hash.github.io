# WATCH•ME CREATIVE — instructions for coding agents

This repository publishes https://watchmecreative.space/ via GitHub Pages.

## Non-negotiable visual invariants
- Preserve the existing aesthetic **exactly**. The source of truth is the current root `index.html`, especially its CSS rules, spacing, typography, buttons, logo, backgrounds, lines, and responsive design.
- **Only the existing font families:** Cormorant Garamond for display and Inter for body. Do not introduce any other fonts, font imports, libraries, UI kits, CSS frameworks, or default component themes.
- **Only the existing colour tokens:** `--ink`, `--ink-2`, `--wine`, `--wine-hi`, `--cream`, `--champagne`, `--mute`, `--line`. Do not invent a palette, new accent, gradients, shadows, cards or design motifs.
- The AI news section `/news/` inherits the original CSS, located at `news/site.css`. Update the shared style from the source, not a visual approximation.
- Do not remove or rewrite the intro animation, hero, bilingual EN/RU strings, client CTAs, tracking attributes, existing links, SEO metadata, or working components of the home page. Minimal patches only.
- Verify desktop AND mobile; watch 320–430px widths and dynamic language changes.

## NEWS content workflow
- Source leads from the agency's confirmed weekly AI/SMM brief; validate important claims with dated official sources before publication.
- Pick consequential changes in neural networks, ChatGPT, AI marketing, website building and small-business automation; avoid low-value generic AI news.
- Story format: **What changed → why it matters → how to apply it → source**. Business Hub instructional pieces should carry actual step-by-step instructions on the site itself, not hide essential text in PDFs.
- Do not fabricate case studies, client figures, timelines, product eligibility, testimonials, images or release dates. Distinguish verified facts from suggestions and experiments.
- Each story must have a separate crawlable HTML URL, real visible article text, byline WATCH•ME CREATIVE, published/updated dates, H1/H2/H3, title/description, canonical, OG, and appropriate Article/NewsArticle JSON-LD.
- Add public new URLs to `sitemap.xml` and make sure `robots.txt` permits search crawlers, including OAI-SearchBot.
- Internal news navigation must work; always preserve navigation back to main site, including on mobile.

## Release control
- Work on a feature branch and open a **draft pull request**.
- Never merge, deploy, or bulk-publish autogenerated articles without an editorial and visual review.
- Do not claim the pages are indexed before Google Search Console confirms this.
